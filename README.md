# Han-Phonics 🇰🇷🔡

An interactive, electronic-whiteboard-optimized Hangul (Korean Phonics) learning web application designed for elementary school students. 

## ✨ Key Features
- **Smart Dynamic Grid Systems**: Layouts dynamically adapt and expand based on the number of phonics cards without causing vertical scrollbars.
- **28 Learning Modes**: Includes grouped syllabus sets (following the Korean elementary curriculum) and 19 single consonant learning modes (ㄱ~ㅎ, ㄲ~ㅉ).
- **Text-to-Speech (TTS) Integration**: Built-in, high-quality neural voice playback for over +190 Hangul syllables to teach exact phonics and pronunciation.
- **Interactive Shuffling Tool**: Fully randomized card shuffling system per mode to improve student recognition speeds and retention.
- **Customizable UI**: Intuitive UI providing persistent personalization like dynamic row-color adaptations and tabbed interface for kids.

Built with Vanilla JavaScript, HTML5, CSS Grid, and Edge-TTS Python Backend.
